# Obfuscator - Break Me

A lot of people said obfuscation is no longer needed because of AI.

I don’t think so.

So I made a challenge. I built a small Unity game based on the well-known default Unity project — with a twist. I hid a small Easter egg: a method you have to find. If you find it, recompile the project so that method is called on game start.

You and your studio get a gift from me: one license of my Obfuscator Source for each seat you need ($129.99 + VAT per seat).

Give it a go and prove me wrong.
